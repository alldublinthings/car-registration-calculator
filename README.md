# Car Registration Fee Calculator Widget

A free, embeddable widget that shows what a car costs to register in any US state (all 50 states and Washington, DC).

**Live page:** https://statefeecalculator.com/
**Widget demo:** open `index.html`, or the GitHub Pages URL for this repo.

## Embed it

```html
<iframe
  src="https://statefeecalculator.com/embed/registration-cost/"
  title="Car registration cost by state"
  width="100%" height="230" style="border:0;max-width:520px"
  loading="lazy"></iframe>
```

The widget is responsive, loads fast, sets no cookies, and needs no scripts of your own.

## Data

Figures are drawn from published state DMV and tax-authority schedules. Full breakdowns, with the source behind every fee, live on [State Fee Calculator](https://statefeecalculator.com/).

Estimates are for planning only; local county fees may apply.
